# PRD → PR reference factory

The reference factory that proves Conveyor works end to end: it takes a PRD through
requirements, task breakdown, implementation, validation, code review and human approval.

It is a uv workspace member that is not published. The factory definition, agents,
contracts and scorers are added here as Conveyor's core capabilities land. See
[`docs/project-overview.md`](../../docs/project-overview.md#reference-factory-prd--pr).
